### Open-Source Text-to-Speech (TTS) Models Literature Review

| Model Name         | Key Features                                                                                                                                              | Limitations                                 | License               | Link                                                                                                                                               | My Feelings After Testing                                  | Notes |
|--------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------|------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------|-------|
| **Kokoro v1.0**     | - Open-weight TTS model with 0.8B params  <br> - Lightweight yet high-quality <br> - Fast and cost-efficient                                                | English only                                | Apache                | [GitHub](https://github.com/hexgrad/kokoro) <br> [Hugging Face](https://huggingface.co/hexgrad/Kokoro-82M#releases)                                | Fast & Accurate, but cannot pronounce Chinese characters     |       |
| **ChatTTS**         | - High-quality bilingual (EN/CH) synthesis <br> - Dialogue optimization <br> - Token-level control                                                          | EN/CH only <br> Limited emotional control <br> Occasional instability | APGL 3.0              | [GitHub](https://github.com/2noise/ChatTTS) <br> [Hugging Face](https://huggingface.co/2Noise/ChatTTS)                                              | Slow and less natural                                       |       |
| **MeloTTS**         | - Multilingual with dialects <br> - Real-time inference on CPU <br> - Free for commercial use                                                              | No voice cloning support                    | MIT License           | [GitHub](https://github.com/myshell-ai/MeloTTS)                                                                                                     | Accurate but a little slower than Kokoro                    |       |
| **OpenVoice v2**    | - Instant voice cloning <br> - Emotion/accent/rhythm control <br> - Cross-lingual cloning                                                                   | Less natural than MeloTTS <br> Fewer languages | MIT License           | [GitHub](https://github.com/myshell-ai/OpenVoice)                                                                                                   | Did not try — seems worse than MeloTTS                      |       |
| **XTTS-v2**         | - Voice cloning with 6s sample <br> - Supports 17 languages <br> - Emotion/style transfer <br> - Low latency (<150ms)                                       | Non-commercial use only                     | Coqui Public License  | [Hugging Face](https://huggingface.co/coqui/XTTS-v2) <br> [GitHub](https://github.com/coqui-ai/TTS)                                                | Accurate & fast, but license may limit use                  |       |
| **Fish Speech v1.5**| - Trained on 1M+ hours <br> - 8+ languages including Arabic                                                                                                  | Non-commercial use only (BY-CC-NC-SA-4.0)  | BY-CC-NC-SA-4.0       | [GitHub](https://github.com/fishaudio/fish-speech) <br> [Hugging Face](https://huggingface.co/fishaudio/fish-speech-1.5)                           | Did not try — restricted by license                         |       |
